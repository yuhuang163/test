# WebRTC 远控验证清单

Agent **源码**在上位机仓库 `new_product_test/remote_agent/`（Git）。  
**运行时** `bin/remote_agent/`（`remote_agent.exe` + `_internal`）**不入库**，发版时拷进安装包。

## 本机环回（可不配 TURN）

1. 启动 factory-api（8800）与 factory-admin（5173）。
2. Agent 二选一：
   - 产线同款：`remote_agent/build_exe.bat`，确认 `bin/remote_agent/exe` + `_internal`
   - 开发：`remote_agent/setup_dev.bat`（venv；上位机会回退到仓库 `remote_agent/`）
3. 启动上位机并登录云端（心跳正常）。
4. 管理端 → **远程桌面** → 选本机设备 → **开始远控**。
5. 数秒内应出现画面；点击画面区域可键鼠操作。

## 跨网（需 coturn）

1. 按 `scripts/coturn-setup.txt` 部署 TURN，配置 `.env` 的 `TURN_*`。
2. IIS ARR 启用 WebSocket proxy。
3. 外网打开 `https://fctp.luteos.com` 远控工厂机。
4. Chrome `chrome://webrtc-internals` 中 selected candidate 含 **relay** 即中继成功。

## 常见问题

| 现象 | 排查 |
|------|------|
| 信令 WebSocket 失败 | IIS 未装「WebSocket 协议」/ ARR 未勾 Enable WebSocket proxy / 未 iisreset；见 scripts/iis-setup.txt 第四节 |
| 一直「等待 Agent」 | 上位机未拉到命令；看日志 `[RemoteDesktop]`；产线缺 `bin/remote_agent`（含 `_internal`）；开发未跑 `setup_dev.bat` |
| Agent 闪退 | 看上位机日志 `[RemoteDesktop]`；杀软拦截；onedir 缺 `_internal` |
| 有画面无键鼠 | 点一下画面使舞台获焦；检查 DataChannel `input` 是否 open |
