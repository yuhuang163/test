# 工站设备能力绑定 — 计划单

## 目标

工程师在编排页为工站绑定「本站会用到的能力」；配步骤时用「目标设备」一条下拉，隐藏通道/协议专业项。  
步骤 ini 仍写完整 `Channel` / `Protocol` / `Device` / `DeviceCmd`，运行时不变。

## 明确豁免（不影响现有产线）

| 模块 | 约定 |
|------|------|
| 自动扫码 `[PreStart_Monitor]` | 独立配置与运行时；**不**纳入 StationBindings 校验 |
| PLC / XWD 监控与步骤共用串口 | `QFreeWorkBox` 已有共享 `SerialChannel` / Modbus 复用逻辑；绑定**只改编排 UI**，**不改**开端口、互斥、复用 |
| Dongle 开测旁路 `BleScanConnect` | `startTask` 等旁路继续可用；绑定不拦截运行时 AT |
| `[SerialUi]` | 继续只管界面串口显隐/文案，与绑定并列 |

原则：**绑定只约束「步骤编辑可选范围」；预启动、扫码、共享通讯、开测旁路零改动。**

## 数据（`profiles/<工站>/flow.ini`）

```ini
[StationBindings]
Configured=true
ProductProtocols=Qroot,Qfctp
EnableProduct=true
EnableProductSerial=false
EnableDongle=true
EnableCloud=true
Fixtures=XWD,ASD9026A
ModbusDevices=GcSeriesTcp
ScpiDevices=
DefaultTarget=product:Qroot
```

- 产品协议**可多选**（组装线常态：Qroot/Qroot2 + Qfctp）。
- `Configured=false`（未保存过）：步骤编辑保持旧 UI（通道+协议全量）。

## 步骤 UI

- 已绑定：显示「目标设备」；隐藏通道、协议/外设行；选目标 → 内部填 Channel+Protocol/Device；指令表按目标过滤。
- 目标键：`product:Qroot`、`fixture:XWD`、`modbus:GcSeriesTcp`、`scpi:Agilent66319d`、`dongle`、`cloud`、`product_serial:…`。
- Hook / 弹窗：沿用现有，不并入目标设备。

## 存量工站自动绑定

- `inferStationBindingsFromFlowSteps`：扫描主流程+失败区步骤的 Channel/Protocol/Device。
- `loadStationBindings`：若尚未 `Configured`（或绑定内容为空），自动按步骤扫描并写入 `[StationBindings]`，无需逐站手工重配。
- 编排页提供「按现有步骤重新扫描」按钮，确认后保存。

## 实施顺序

1. 类型 + load/save + 按站名推断默认（不强制 Configured）
2. 编排页「设备能力绑定」对话框 + 保存提示
3. 步骤编辑目标设备模式
4. 按现有步骤自动扫描落盘（存量兼容）
5. CRLF + Release `-SkipQmake` 编译验证

## 验收

- 未绑定时：步骤编辑与现在一致。
- 绑好后：只见本站目标；保存后 steps ini 仍有正确 Channel/Protocol。
- 自动扫码、PLC/XWD 共享口、流程里 Dongle/Modbus 步骤：行为与改造前一致。
