## 前言

本说明描述「新产品测试上位机」的日常界面操作，重点覆盖：

- 软件启动、登录与工站切换；
- **自由工站**窗口的扫码开测、串口连接与结果查看；
- **上位机设置**中的 MES、一拖多、阈值与 **测试流程编排**；
- 测试步骤（功能块）的编辑、合格判定与特殊步骤；
- 一拖多场景下程控电源 / 温度仪等外设的步骤参数配置。

文档结构参考 `docs/VDS2100使用指导规范（初稿）.pdf`（范围 → 术语 → 要求 → 界面介绍 → 分步操作），结合本仓库当前界面文案整理。界面以实机为准；若与本文不一致，以实际软件菜单与对话框文字为准。

**读者**：产线操作员、工艺工程师、产测维护人员。

---

## 1 范围

本说明适用于本仓库编译产出的 Windows 上位机在以下场景中的使用：

1. 自由工站（`FREE_WORK`）按流程编排执行产品测试；
2. 通过「功能设置」配置工站类型、MES、一拖多布局与测试流程；
3. 连接 Dongle / 治具 / 产品串口 / 万用表等外设后扫码开测。

不包含：各产品固件协议细节、MES 后台配置、云端平台运维、以及专项工站（按键 / 吸力 / 静态电流等）内部状态机的深度原理。专项工站的开测方式与自由工站类似处可参照第 6 章。

## 3 术语和定义

| 术语 | 定义 |
|------|------|
| 上位机 | 本程序 `new_production.exe`，用于产线测试与设备控制 |
| 工站类型 | `SYSTEM/station` 配置的当前窗口类型，如自由工站、吸力工站等 |
| 自由工站 | 按「测试流程编排」执行可配置步骤序列的工站窗口 |
| 一拖多 | 同一工站窗口内按「行 × 列」显示多个工位界面 |
| 功能块 / 步骤 | 流程中的一个测试项，对应 `test_case` 下的 ini |
| Profile | 某一产品工站下的流程与步骤覆盖配置 |
| Gate | 根据设备回传结果判定通过 / 失败 |
| Hook | 不走普通指令、走预置复杂流程的特殊步骤 |
| VISA | 程控仪器资源访问接口（如 GPIB / TCPIP 程控电源） |
| sharedPair | 步骤参数：启用多工位共享同一台外设（电源 / 温度仪等） |

## 4 要求

### 4.1 人员要求

| 角色 | 建议具备能力 |
|------|----------------|
| 操作员 | 能扫码、选串口、看通过 / 失败与日志；一般不进入「功能设置」 |
| 工艺工程师 | 能配置工站、MES、流程编排与步骤参数；具备管理员或工艺工程师账号 |
| 维护人员 | 能排查串口占用、VISA 连接、流程失败项与上位机日志 |

### 4.2 设备要求（典型自由工站）

按实际工序配置，常见包括：

- PC（已安装本上位机及依赖，如 NI-VISA）；
- 蓝牙 Dongle 及串口线；
- 治具 / 夹具串口（如需）；
- 产品串口仪器、万用表或电流表（如需）；
- 程控电源（Agilent 66319D / 会凌 WFP60H 等，如需）；
- 多路温度记录仪（如需）。

### 4.3 文件要求

- 程序目录下存在 `上位机设置.ini`；
- `test_case/steps/` 与对应 `test_case/profiles/<工站名>/` 流程与步骤完整；
- 使用程控电源时，步骤中已配置正确的 VISA 地址与 SCPI 模板。

### 4.4 环境要求

1. 串口未被其它软件占用（如 NI Communicator 占用 GPIB 时，请先关闭）；
2. 需要 MES 时网络可达对应 MES / 云平台地址；
3. 扫码枪切换为英文输入后再扫码。

## 5 软件界面介绍

### 5.1 启动与登录

1. 运行 `new_production.exe`；
2. 按提示完成云平台 / 账号登录（若启用）；
3. 状态栏可查看登录状态，例如「云平台：已登录」或「未登录」；
4. 程序根据 `SYSTEM/station` 打开对应工站窗口（如标题 **自由工站**）。

### 5.2 菜单栏（各工站窗口通用）

| 菜单 / 项 | 说明 |
|-----------|------|
| **功能设置** | 打开「上位机设置」。仅管理员或工艺工程师可见；否则提示权限不足 |
| **连接治具串口** | （自由工站）打开治具串口连接窗口 |
| **帮助 → 切换账号** | 切换登录账号 |
| **帮助 → 上传日志** | 上传本机日志 |
| **帮助 → 检查更新...** | 检查程序更新 |

### 5.3 自由工站主界面

一拖多时，同一窗口内按「行 × 列」并列多个工位面板，每个工位操作相同。

#### 5.3.1 主要 Tab

| Tab | 说明 |
|-----|------|
| 首 Tab（名称随当前流程工站变化） | 扫码、串口、停止、测试结果表 |
| **待拓展** | 扩展项（如 Wi-Fi / RSSI 等） |
| **图形展示** | Dongle 双通道吸力曲线等；可清空曲线 |
| **蓝牙绑定工站** | 扫码绑定 MAC–SN |
| **日志** | 本工位运行日志 |

#### 5.3.2 首 Tab 关键控件

| 控件文案 | 作用 |
|----------|------|
| **输入SN获取mac：** | 扫 SN 后回车，解析或经 MES 取 MAC，并开始测试 |
| **输入MAC连接：** | 直接输入 / 扫描 MAC 后回车开始测试 |
| **停止测试** | 中止当前工位测试 |
| **测试(开发用)** | 开发调试入口，产线勿用 |
| **是否从mes获取mac** | 勾选后按 MES 规则取 MAC |
| **是否过站** | 勾选后测试结果参与 MES 过站 |
| **用时** / **蓝牙连接：** | 显示测试耗时与连接状态 |
| **三元组位置** | 左 / 右 / 单只 / 未指定 |

#### 5.3.3 串口区

| 区域 | 操作 |
|------|------|
| 首行串口下拉 + **连接串口** / **断开连接** | **Dongle** 串口 |
| **治具串口** + 连接 / 断开 | 治具通信 |
| **产品串口(仪器)** | 产品侧仪器串口 |
| **万用表串口** | USB / 万用表 / Modbus RTU 等 |

菜单 **连接治具串口** 可打开独立「治具串口」窗口，用于配置主治具口（一拖多共享场景常用）。

### 5.4 上位机设置窗口

入口：菜单 **功能设置** → 窗口标题 **上位机设置**。

| Tab | 主要内容 |
|-----|----------|
| **关键设置** | 工站选择、MES、一拖多行列、产品差异化开关等 |
| **测试流程编排** | 工站 Profile、主流程、失败执行区、云端上传下载 |
| **测试详细配置** | 电流阈值、按键、射频 PER、三元组、PLC 等专项参数 |

关闭设置窗口时会自动保存配置。切换工站类型后程序会提示并重启以加载新窗口。

## 6 操作说明 — 操作员（日常测试）

### 6.1 开测前检查

1. 确认窗口标题为当前工序对应工站（如 **自由工站**）；
2. 确认首 Tab 显示的流程名称与本工位产品一致；
3. 按工序连接所需串口，状态显示连接成功；
4. 需要过站时勾选 **是否过站**；需要 MES 取 MAC 时勾选 **是否从mes获取mac**；
5. 扫码枪切换为英文输入。

### 6.2 连接串口（示例）

**A. 连接 Dongle**

1. 在首行串口下拉框选择 Dongle 对应 COM 口；
2. 点击 **连接串口**；
3. 日志中出现 Dongle 连接成功类提示。

**B. 连接治具**

1. 在 **治具串口** 下拉框选择端口，点击 **连接串口**；  
   或菜单 **连接治具串口** → 在弹窗中选择端口并连接。

**C. 连接产品串口 / 万用表**

1. 在对应区域选择端口；
2. 点击 **连接串口**。

### 6.3 开始测试

自由工站 **没有单独的「开始」大按钮**，开测方式为：

1. 将光标点到 **输入SN获取mac：** 或 **输入MAC连接：**；
2. 扫描条码或输入后按回车；
3. 软件自动连接蓝牙（如需）并按编排流程逐步执行；
4. 结果表显示各项通过 / 失败；**日志** Tab 可查看详细过程。

### 6.4 停止与异常

1. 点击 **停止测试** 可中止当前流程；
2. 失败时若流程配置了「测试失败执行区域」，会自动执行收尾步骤（如断电、抬气缸等）；
3. 连续失败时检查：串口是否掉线、产品是否在治具内、Dongle 是否被占用、流程是否已保存。

### 6.5 查看结果与日志

1. 首 Tab 结果表：分项结果、通过 / 失败；
2. **日志** Tab：步骤下发、回包、卡控说明；
3. 需要上传日志时：菜单 **帮助 → 上传日志**。

## 7 操作说明 — 工艺工程师（配置）

### 7.1 选择工站类型

1. 打开 **功能设置** → **关键设置** → **1、工站选择**；
2. 勾选目标工站（如 **自由工站上位机**）；
3. 程序保存并重启，进入对应窗口。

常见选项示例：调试上位机、静态电流、按键测试、吸力测试、**自由工站上位机** 等。

### 7.2 配置一拖多

1. 在 **关键设置** → **1拖多设置** 中填写 **行**、**列**；
2. 例如 2 行 × 2 列 = 一拖四；
3. 重启进入工站后，窗口内出现多个工位面板。

### 7.3 配置 MES（如需）

在 **关键设置** → **2、MES相关设置** 中配置：

- **工厂**、**工站**、**mes网址**、**工序名称**、**机种名称**、**线体** 等；
- 用户名 / 密码、操作员号、站前检查相关选项。

具体字段以当前工厂 MES 对接要求为准。

### 7.4 测试流程编排

入口：**上位机设置** → **测试流程编排**。

| 操作 | 步骤 |
|------|------|
| 选择工站 Profile | 在 **工站** 下拉框选择（可按 **产品名字** 过滤） |
| 添加工能块 | 流程空白处右键 → **添加已有块** / **添加空白块**；可用搜索 |
| 调整顺序 | 拖拽，或选中后点 **上移** / **下移** |
| 编辑步骤 | 功能块右键 → **打开设置** |
| 单步调试 | 功能块右键 → **运行**（需已打开自由工站窗口） |
| 失败收尾 | 在下方 **测试失败执行区域** 添加断电、抬气缸等步骤 |
| 保存 | 必须点击 **保存流程**，否则拖拽 / 增删不生效 |
| 云端 | **下载工站用例** / **上传本工站用例**（按工厂云端策略使用） |

勾选 **测试失败时结束测试流程**：主流程某步失败后停止，并执行失败区步骤。

### 7.5 测试项配置（步骤编辑）

功能块右键 → **打开设置** → 对话框 **测试项配置**。

#### 7.5.1 测试项信息

- **名称**：步骤显示名；
- **上报MES的字段**：过站字段名，同一流程内勿重复；
- **测试时弹出操作提示** / **提示文字**：操作员确认类提示；
- **不发送指令（PromptOnly）**：仅提示确认，不发设备指令。

#### 7.5.2 测试指令

| 项 | 说明 |
|----|------|
| **通信类型** | 产品蓝牙 / 产品串口 / Dongle / 云端 / 治具 / Modbus / **SCPI** |
| **产品协议** / **操作方式** / **指令内容** | 按设备与动作选择 |
| **指令参数** | 表格两列：**参数名（中文）**、**参数值**；鼠标悬停参数名可看英文键；添加行时输入英文键名 |

#### 7.5.3 等待时间

- **执行前等待**、**完成后等待**、**指令超时(毫秒)**。

#### 7.5.4 合格判定（Gate）

1. 勾选 **根据设备回传结果判定通过/失败**；
2. 选择回传数据类型、判定项目与方式（范围内 / 大于 / 小于 / 等于 / 版本比对等）；
3. 填写上下限或期望值。

说明：部分按键步骤在 Gate 开启等待回传时，界面可能不显示「是」按钮，由设备上报自动进入下一步。

#### 7.5.5 特殊步骤（Hook）

勾选 **不用测试指令，走预置复杂流程**，并选择预置流程类型（如蓝牙按名连接、Dongle 吸力采样等）。仅工程师需要时使用。

编辑完成后点 **Save** 保存步骤。

## 8 程控电源与一拖多共享配置（步骤参数）

> 多工位共用程控电源 / 温度仪时，配置写在 **测试步骤参数** 中，不依赖「上位机设置」里的全局开关。

### 8.1 配置 Visa 程控电源（典型）

1. 流程中加入「配置Visa程控电源」等 SCPI 步骤；
2. 通信类型选 **SCPI通信**，设备选 Agilent66319d 或会凌等；
3. 在参数表中配置电压、限流、SCPI 模板与地址。

**单电源（一工位一台）示例含义：**

| 界面中文名（示例） | 含义 |
|--------------------|------|
| VISA 资源地址（单电源） | 如 `GPIB0::7::INSTR` |
| 电压 (V) / 限流 (A) | 输出设定 |
| 打开 / 关闭输出 SCPI 等 | 命令模板 |

**一拖多共享（每 2 工位共用一台双通道电源）示例：**

| 界面中文名（示例） | 建议值说明 |
|--------------------|------------|
| 启用多工位共享外设 | `true` |
| 每台设备对应工位数 | `2`（每 3 工位共享则填 `3`） |
| 第 1 / 第 2 台程控电源 VISA 地址 | `visaAddress0` / `visaAddress1` |
| 选通道 SCPI | 如 `INST OUT%1`（Agilent） |

映射关系（`stationsPerDevice=2`、一拖四）：

| 工位 | 设备 | 通道 |
|------|------|------|
| 1 | 第 1 台 | CH1 |
| 2 | 第 1 台 | CH2 |
| 3 | 第 2 台 | CH1 |
| 4 | 第 2 台 | CH2 |

一拖六且每 2 工位共享时，再增加第 3 台地址即可。运行日志中会出现类似「共享程控电源：工位 n → VISA 设备 …」的提示。

### 8.2 温度记录仪共享（16 路 / 法兰加热）

每 **2 台设备**对应 **1 台**多路温度记录仪（设备支持多路，常用 16 通道）：

| 同仪内工位 | 通道 |
|------------|------|
| 第 1 台（如工位 1 / 3） | CH1～CH6 |
| 第 2 台（如工位 2 / 4） | CH7～CH12 |

步骤参数要点：`sharedPair=true`、`stationsPerDevice=2`、`channelsPerStation=6`、`tempComName0/1`、`sampleDurationMs=20000`。  
判定：在窗口时间内（默认 20s），某一轮采样中该工位 **6 个加热点全部**落入 Gate 温度范围（法兰加热为 **41±2℃**，即 39～43℃）则通过。

### 8.3 注意事项

1. 使用 GPIB 前关闭 NI Communicator 等可能独占仪器的软件；
2. 配置步执行后，同流程后续「打开 / 关闭 / 读电流」会复用地址与通道映射；
3. 选通命令以仪器手册为准；若不是 `INST OUT%1`，在步骤参数中改「选通道 SCPI」。

## 9 常见问题（UI 侧）

| 现象 | 可能原因 | 处理建议 |
|------|----------|----------|
| 看不到「功能设置」 | 账号权限不足 | 使用管理员 / 工艺工程师账号 |
| 扫码无反应 | 输入法非英文、焦点不在输入框 | 切英文，点击 SN/MAC 输入框后再扫 |
| 连接串口失败 | 口被占用或选错 | 关闭其它占用程序，重选 COM |
| 流程不更新 | 编排后未保存 | 点 **保存流程** |
| VISA 写失败 / ABORT | 会话冲突或地址错误 | 关 Communicator，核对步骤中的地址 |
| 两工位抢同一电源通道 | 未开 sharedPair 或地址表不全 | 检查共享参数与 `stationsPerDevice` |
| 单步「运行」无效 | 未打开自由工站窗口 | 先进入自由工站再单步 |
