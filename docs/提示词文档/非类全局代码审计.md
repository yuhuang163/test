# 非类全局代码审计 — 上位机业务模块

> **一句话**：对照「模块皆类」约定，梳理业务代码中的自由函数 / 匿名命名空间 / 可变全局态，并标出优先收敛项。  
> **读者**：开发。**前提**：只读审计，不含改码；已排除第三方、`Python39`、xlsx、qcustomplot、moc/ui 生成物。

## 1. 范围

### 包含
- `platform/`、`work_station/`、`business/`、`agreement/`（业务）、`common/`、`qlog/`、主窗口周边

### 不包含（边界）
- 第三方与生成代码、`main` 入口本身
- 仅讨论「是否类外全局」，不涉及命名风格以外的架构重构方案细节

## 2. 结论

业务 `.cpp` 中含匿名命名空间约 **60+** 文件。相对「一切皆类」：

| 判定 | 含义 |
|------|------|
| **违规** | 对外自由函数 API、登记入口、或模块级可变全局态 — 优先收敛 |
| **灰** | 文件内匿名 ns / `static` 局部助手 — 风格不符，多数非跨模块状态 |
| **可接受** | 工具类、类单例、清单表/注册表、类背后的 Meyers 存储 |

## 3. 审计表

| 等级 | 模块/文件 | 形态 | 代表符号 | 约量 |
|------|-----------|------|----------|------|
| **违规** | `platform/test_case/test_case_ini_param.*` | 头文件自由函数簇 | `writeSendParamMap`、`readSendParamMap` 等 | ~18 |
| **违规** | `platform/settings/qsetting_bindings.*` | 全局 API | `load/saveQSettingTableBindings` | 3 |
| **违规** | `TestCasePaths`（`test_case.h`） | 命名空间自由函数 | `rootDir`、`profileDir`… | ~15 |
| **违规** | 登记入口 | 全局 `register*` | `registerAllGateAccessorTypes`、`registerFreeWork*`、`registerQFreeWorkCatalog*` | ~3 |
| **违规** | `work_station/freework/qfreework.cpp` | 文件 `static` 业务助手 | `appendOneMesStep` 等 | ~5 |
| **违规** | `serial_channel` / 部分 cloud | 匿名 ns **可变**状态 | 口列表缓存、`g_*` mutex/表 | 若干 |
| **灰** | `test_case_gate.cpp` | 匿名 ns + 自由函数 | `fieldStringFromVariant`、描述大表 | 多块 |
| **灰** | 各工站 / 协议 `.cpp` | 匿名 ns 局部助手 | 常量、一次性小工具 | ~60 文件 |
| **可接受** | `GateAccessorRegistry` | 类 + Meyers 存储 | `gateTypeStore()`、`gateFieldMatches` | 实现细节 |
| **可接受** | `*CmdManifest` / device catalog | 具名 ns 清单表 | `DongleCmdManifest::rowCount` 等 | ~12 套 |
| **可接受** | `CommonUtils`、`SETTINGS` | 工具类 / 类单例 | — | — |

## 4. 优先收敛顺序

1. `test_case_ini_param` → 收成类，或并入 `TestCaseStore` 静态成员  
2. `qsetting_bindings` → 并入 `qsetting`  
3. `TestCasePaths` + `register*` → 类静态 API  
4. 可变 `g_*` / 串口缓存 → 收进对应 Service / Channel 类  

**GateAccessor 说明**：对外已是 `GateAccessorRegistry`；非类的是旁路入口 `registerAllGateAccessorTypes()`（示意文件中的 `registerJieliBtBoxGate` 同类）。

## 5. 验证

后续若收敛，可按下列方式自检（改码后再跑）：

| 检查项 | 做法 |
|--------|------|
| 头文件自由函数 | 在 `platform/`、`work_station/` 搜行首 `^(void\|bool\|QString\|int)\s+\w+\(`，排除类声明与工具例外 |
| 匿名命名空间 | `rg '^namespace \{' --glob '*.cpp'`，对照本表灰/违规分级 |
| 可变全局 | 搜 `g_`、文件作用域可变 `static` 容器/mutex |
| 编译 | `scripts\编译Release版本.ps1 -SkipQmake` |

## 6. 常见问题

| 现象 | 原因 | 处理 |
|------|------|------|
| 清单 `*CmdManifest` 也是自由函数 | 约定允许的具名 ns 数据表 | 可不收敛，或仅统一命名 |
| `gateTypeStore()` 像全局 | Meyers 单例藏在类 API 后 | 保持；勿再暴露裸 `QVector` |
| 几乎每个 `.cpp` 都有匿名 ns | 多为局部常量/助手 | 碰文件时再收进类/`static` 成员；勿全仓盲改 |
