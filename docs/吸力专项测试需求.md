# 吸力专项测试 — 需求文档

> 本文档为「吸力专项测试」页（mainwindow.ui 中 `tab_dongle_suction` / `groupBox_dongle_at_pump` 泵/阀参数设置块）的改造需求定稿，供 review。

## 1. 背景与目标

现有「泵/阀参数设置」是固定 4 段（泵工作时间 / 泵后全关 / 阀工作时间 / 阀后全关），且间歇只有 `PUMPOFF` / `VALVEOFF` 两个固定值。本次改造目标：

1. 把固定 4 段改成**通用多段循环**，段数与每段参数都可配。
2. 协议的「间歇」与「工作段」都改成**带段号的通用指令**。
3. 频率 / 占空比从「全局」改为**逐段可配**。
4. 支持**驱动模式切换**（泵阀驱动 / 直线电机驱动）。
5. 界面瘦身，并新增**一键导出参数列表 CSV** 与**一键导出吸力曲线 PNG**。

## 2. 多段循环模型

- 一轮 = **N 段**，N 为**任意偶数**。
- 段严格按「**工作 → 全关 → 工作 → 全关…**」交替。
- 每段时长**逐段可配**；工作段额外含频率、占空比（逐段可配）。
- 一轮这套段参数按 `PUMPTOTAL` 总时长**循环重复**，直到总时长到点停止（0 = 不限）。

## 3. 协议指令集

### 3.1 一键设置下发顺序

```
AT+DRIVE_TYPE=0|1          模式：0 = 泵阀驱动 / 1 = 直线电机驱动
AT+SEGCOUNT=N              每轮段数（任意偶数）
对 i = 1..N/2（工作段）：
  AT+WORKTIME=i,时间       工作段时间（ms）
  AT+PUMPFREQ=i,频率       工作段泵频率（Hz）
  AT+PUMPDUTY=i,占空比     工作段泵占空比（0~100）
对 i = 1..N/2（全关段）：
  AT+INTERVALOFF=i,时间    全关段时间（ms，0 = 不保持全关）
AT+PUMPTOTAL=总时长        总运行时长（ms，0 = 不限）
AT+FGPRINT=间隔            日志上报间隔（ms）
AT+BLEDEVICELOG=0          关闭设备日志（沿用现状）
```

### 3.2 指令变更清单

| 类型 | 指令 |
|------|------|
| 新增 | `AT+DRIVE_TYPE`、`AT+SEGCOUNT`、`AT+WORKTIME=i,时间`、`AT+INTERVALOFF=i,时间` |
| 改造（加段号） | `AT+PUMPFREQ=i,频率`、`AT+PUMPDUTY=i,占空比` |
| 废弃删除 | `PUMPSEC`、`VALVESEC`、`PUMPOFF`、`VALVEOFF`，以及全局 `PUMPDUTY`、`PUMPFREQ` |
| 保留 | `PUMPTOTAL`、`PUMPSTART`、`PUMPSTOP`、`FGPRINT`、`BLEDEVICELOG`、`PUMPSTATUS` |

### 3.3 段序号语义

- 段序号在「一轮」内从 1 递增：工作段 `1..N/2`、全关段 `1..N/2`。
- 一轮这套段参数循环重复，直到 `PUMPTOTAL` 到点。

## 4. 频率 / 占空比

- 每段的泵**频率、占空比都可调**（随工作段逐段配置，不再全局）。
- 逐段指令沿用旧名 + 段号：`AT+PUMPFREQ=i,频率`、`AT+PUMPDUTY=i,占空比`。

## 5. 直线电机模式（DRIVE_TYPE=1）

- 无阀，所有工作段都驱动泵（泵泵交替）。
- 界面工作段标签已泛化为「工作段 i」，不再区分泵/阀；切换模式只改变下发的 `DRIVE_TYPE`。

## 6. 界面改造

位置：[mainwindow.ui](mainwindow.ui#L4976) `groupBox_dongle_at_pump`（吸力专项测试页）。现状 4 行高网格，太高，需压矮。

- **静态骨架（尽量在 .ui 改）**：
  - 第 1 行：驱动方式下拉（泵阀驱动 / 直线电机驱动）+ 每轮段数 spinbox（步进 2、任意偶数）+ 总运行(ms) + 日志上报间隔(ms)。
  - 第 2 行：一键全部设置 / 全部读取 / 开始交替运行 / 立即停止 + 频率实时 label。
  - 新增两个导出按钮：一键导出参数列表 CSV、一键导出吸力曲线 PNG。
- **动态段行（.cpp 生成）**：按 `SEGCOUNT` 生成 `N/2` 行，每行「工作段 i」时间/频率/占空比 + 「全关段 i」时间，放进固定高度可滚动容器。
- **删除旧字段**：泵工作 / 泵后全关 / 阀工作 / 阀后全关、全局占空比 / 全局频率。
- **频率 label 实时刷新**：`60000 ÷（所有段时长之和）`。

## 7. 导出功能

### 7.1 一键导出参数列表（CSV）

- 内容：**只导出泵/阀参数**（驱动方式、每轮段数、各工作段时间/频率/占空比、各全关段时间、总运行、日志上报间隔）。
- 格式：CSV（`参数名,值` 两列），UTF-8。

### 7.2 一键导出吸力曲线（PNG）

- 内容：当前吸力曲线图（QCustomPlot，含 CH1/CH2/CH3 三通道）截图保存为 PNG。

### 7.3 导出路径

- 基目录与现有吸力 CSV 相同（运行目录下，`CommonUtils::ensureLogDirectory` 相对目录），**目录名由「吸力测试数据」改为「吸力专项数据」**。
- 文件命名（待最终确认，暂定）：
  - 参数列表：`吸力专项参数_yyyyMMdd_HHmmss.csv`
  - 吸力曲线：`吸力曲线_yyyyMMdd_HHmmss.png`
