# ASD9026A 协议 — 双通道模拟电池串口通信

ASD9026A 是自由工站（一拖多）使用的**双通道模拟电池 / 治具程控电源**，通过自定义串口帧协议控制输出电压、限流、输出开关并回采实际状态。帧格式以厂商规范 `ASD9026A双通道模拟电池协议.xlsx` 为准，本文按上位机实现整理。

## 1. 数据包格式

### 1.1 帧结构

| 偏移 | 长度 | 字段 | 说明 |
|------|------|------|------|
| 0 | 1 | 模块地址 | 一拖多寻址；上位机按工位 channel 赋值（见 §4） |
| 1 | 1 | 功能码 | 见 §1.2 |
| 2 | 1 | 命令码 | 见 §1.3 |
| 3 | 1 | 数据长度 | payload 字节数 |
| 4 | 变长 | payload | 数据，可为空 |
| 4+L | 2 | CRC16 | 见 §1.4，低字节在前 |

### 1.2 功能码

| 值 | 名称 | 说明 |
|----|------|------|
| `0x10` | 读 | 查询模块信息 / 状态 |
| `0x11` | 写 | 输出开关 |
| `0x12` | 读应答 | 读请求的应答 |
| `0x20` | 模拟量读 | 读模拟电池状态 |
| `0x21` | 模拟量写 | 模拟量配置（恒压 / 限流 / 档位） |
| `0x22` | 模拟量应答 | 模拟量读的应答 |

### 1.3 命令码

| 值 | 名称 | 配合功能码 |
|----|------|-----------|
| `0x01` | 查询模块信息 | `0x10`（枚举已定义，当前驱动未使用） |
| `0x02` | 查询模块状态 | `0x10` |
| `0x04` | 输出开关 | `0x11` |
| `0x10` | 模拟量配置 / 状态 | `0x21` 写 / `0x20` 读 |

### 1.4 校验和 CRC16

CRC16-Modbus，覆盖「模块地址 → payload 末字节」（不含 CRC 自身），追加时**低字节在前**。

```c
quint16 crc16Modbus(const QByteArray& data) {
    quint16 crc = 0xFFFF;
    for (const char byte : data) {
        crc ^= static_cast<quint8>(byte);
        for (int bit = 0; bit < 8; ++bit) {
            if (crc & 0x0001)
                crc = (crc >> 1) ^ 0xA001;
            else
                crc >>= 1;
        }
    }
    return crc;
}
```

追加方式：先 `crc & 0xFF`（CRC_L），再 `(crc >> 8) & 0xFF`（CRC_H）。与 Modbus 工具函数的区别见 `报文CRC计算说明.md` §2。

### 1.5 字节序说明

- CRC：低字节在前。
- 配置帧的电压（µV）、限流（mA）：**大端**。例：4V / 2A → `00 3D 09 00` / `00 00 07 D0`。
- 状态帧的电压 / 电流平均值：**大端**。
- 读模块状态的输出电压（mV）：**小端**（`body[1] | body[2] << 8`）。

## 3. 命令说明

### 3.1 输出开关（`0x11` / `0x04`）

**上位机 → 设备**（payload 3 字节）

| 偏移 | 长度 | 字段 | 说明 |
|------|------|------|------|
| 0 | 1 | 开关 | `0x01` = 开，`0x00` = 关 |
| 1 | 2 | 保留 | `0x00 0x00` |

**设备 → 上位机**：无约定 payload，仅校验帧解析成功且模块地址匹配即视为成功。

### 3.2 模拟量配置（`0x21` / `0x10`）

**上位机 → 设备**（payload 13 字节）

| 偏移 | 长度 | 字段 | 说明 |
|------|------|------|------|
| 0 | 1 | 输出状态 | `0x00` = 不变 |
| 1 | 4 | 电压 | 单位 µV，**大端**。例：4V = `0x3D0900` |
| 5 | 4 | 限流 | 单位 mA，**大端**。例：2A = 2000mA = `0x07D0` |
| 9 | 1 | 电流测量档位 | `1` = 大档，`2` = 中档，`3` = 小档，`4` = 自动（默认） |
| 10 | 1 | 显示速度 | `0x01` = 快，`0x00` = 不变 |
| 11 | 1 | 保留 | `0x00` |
| 12 | 1 | 线阻 | `0x00` |

**设备 → 上位机**（应答 3 字节）：功能码 `0x12`、命令码 `0xFF`、`body[2]` 回显 `0x10`。上位机按「功能码 = 0x12、命令码 = 0xFF、body 长度 3、body[2] = 0x10」校验成功。

示例（4V / 2A，模块地址 `0x01`）：

```
01 21 10 0D 00 00 3D 09 00 00 00 07 D0 04 01 00 00 <CRC_L> <CRC_H>
```

### 3.3 电流量程切换（`0x21` / `0x10`）

与 §3.2 同一帧，仅改档位字段：电压 / 限流填 `0`（不变）、档位填 `1~4`、显示速度与线阻填 `0`。应答校验同 §3.2。

### 3.4 查询模块状态（`0x10` / `0x02`）

**上位机 → 设备**：无 payload。

**设备 → 上位机**（功能码 `0x12`、命令码 `0x02`，body ≥ 3 字节）

| 偏移 | 长度 | 字段 | 说明 |
|------|------|------|------|
| 0 | 1 | 保留 | 未使用 |
| 1 | 2 | 输出电压 | 单位 mV，**小端** |

> 电流暂未解析（上位机 `outputMilliAmps` 固定为 0）。

### 3.5 读模拟电池状态（`0x20` / `0x10`）

**上位机 → 设备**：无 payload。

**设备 → 上位机**（功能码 `0x22`、命令码 `0x10`，body 14 字节 `0x0E`）

| 偏移 | 长度 | 字段 | 说明 |
|------|------|------|------|
| 0 | 1 | 输出状态 | `0` = 关，非 `0` = 开 |
| 1 | 4 | 电压平均值 | **大端** |
| 5 | 1 | 电压单位码 | 见下表 |
| 6 | 4 | 电流平均值 | **大端** |
| 10 | 1 | 电流单位码 | 见下表 |
| 11 | 1 | 保留 | — |
| 12 | 1 | 温度 | raw − 40；`0xFF` 表示无（取 0） |
| 13 | 1 | 保留 | — |

**单位码 → 基单位换算**（电压 → V，电流 → A）

| 单位码 | 电压 | 电流 | 换算 |
|--------|------|------|------|
| `1` | V | A | × 1 |
| `2` | mV | mA | ÷ 1000 |
| `3` | µV | µA | ÷ 10⁶ |
| `4` | nV | nA | ÷ 10⁹ |
| `0` / 未知 | µV | µA | ÷ 10⁶ |

示例：`00 00 00 0C` + 单位 `1` → 12V；`00 00 09 C0` + 单位 `2` → 2496mA。
