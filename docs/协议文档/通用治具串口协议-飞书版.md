## 1. 概述

本协议定义上位机与通用产测治具之间的串口通信。治具须实现：

1. **气缸控制**：下压、复位（抬起）；**到位后必须应答**
2. **继电器控制**：多路独立吸合 / 断开；**动作完成后必须应答**
3. **电流读取**：按通道应答测量值
4. **一拖多**：同一治具（或同一串口总线上的多工位）用 **SLOT 机位号** 区分，请求与应答均携带 SLOT

联调以本文件字节定义为准。未写明行为视为未定义；保留字段、保留 TYPE/CH/SLOT 在书面变更前不得占用。

**控制硬性约定**：上位机发出 TYPE=`0x01` 控制帧后，治具须在目标状态**真正到位 / 动作完成**后回 TYPE=`0x81`；禁止仅「收包受理」就回成功，也禁止控制无应答。

## 2. 一拖多拓扑（先读）

### 2.1 支持的形态

| 形态 | 说明 | SLOT 用法 |
|------|------|-----------|
| A. 一机多槽 | 一块治具 MCU，多工位气缸/继电器/采样，**共用一根串口** | 每帧带目标 SLOT=`1~N` |
| B. 一工位一串口 | 每工位独立串口（上位机开多个 COM） | 该口上固定 `SLOT=0x01`，或按工位号填写 |
| C. 广播动作 | 多工位同时气缸/上电（仅控制帧） | `SLOT=0x00`，见 §4.5 |

### 2.2 硬性要求

1. **所有下行 / 上行业务帧必须带 SLOT**（见 §3），禁止无槽位的隐式帧。
2. 应答帧的 SLOT **必须与请求一致**（广播控制见 §4.5：按实际工位各回一帧），便于一拖多时上位机归属到对应工位。
3. 共用一根串口时：治具按帧处理，可连续收多工位指令；**同一时刻同一执行器资源**若硬件互斥，须在说明书中声明，并由上位机串行调度。
4. 上位机一拖多时会对共享串口**串行发帧**；治具不得因短间隔连包死机或错槽动作。
5. **每条控制请求必须有到位应答**（§4.4）；上位机以 `0x81` 且 `STATUS=0x00` 作为「可进入下一步」的依据，不得依赖固定延时代替到位。

### 2.3 机位号 SLOT

| SLOT | 含义 |
|------|------|
| `0x00` | **广播**（仅允许用于控制帧 TYPE=`0x01`；测量请求禁止广播） |
| `0x01` ~ `0x0F` | 工位 / 槽位 1 ~ 15 |
| `0x10` ~ `0xFF` | 保留 |

供应商须在说明书中写明：支持的最大槽位数 N（1~15）、各 SLOT 对应的物理工位编号。

## 3. 物理层与通用帧规则

### 3.1 物理层

| 项 | 要求 |
|----|------|
| 接口 | UART（TTL / RS-232，与硬件约定一致） |
| 波特率 | **115200** |
| 数据位 / 校验 / 停止位 | 8 / None / 1 |
| 流控 | 无 |
| 编码 | **仅二进制**，禁止文本与 `\r`/`\n` 行协议 |
| 字节序 | 多字节整数 **大端** |
| 帧间隔 | 建议 ≥ 5ms（一拖多连发时上位机保证；治具仍须能处理更短间隔） |

### 3.2 帧头与 TYPE

第 0 字节固定 `0x55`。

| TYPE | 方向 | 含义 | 帧长 |
|------|------|------|------|
| `0x01` | 下行 | 执行器控制 | 固定 **6** 字节 |
| `0x02` | 下行 | 测量请求（读电流） | 固定 **6** 字节 |
| `0x81` | 上行 | **控制到位应答（强制）** | 固定 **7** 字节 |
| `0x82` | 上行 | 测量应答 | 固定 **11** 字节（`LEN=0x0B`） |

未列出 TYPE：治具忽略，不得误动作。

### 3.3 切帧

| TYPE | 规则 |
|------|------|
| `0x01` / `0x02` | 固定 6 字节 |
| `0x81` | 固定 7 字节 |
| `0x82` | 第 2 字节为 `LEN`，按 `LEN` 取整帧；本版必须 `LEN=0x0B` |

## 4. 执行器控制（气缸 / 继电器）

### 4.1 请求帧（上位机 → 治具，6 字节）

| 偏移 | 长度 | 字段 | 说明 |
|------|------|------|------|
| 0 | 1 | SOF | `0x55` |
| 1 | 1 | TYPE | `0x01` |
| 2 | 1 | SLOT | 机位，见 §2.3 |
| 3 | 1 | CH | 通道，见 §4.2 |
| 4 | 1 | RES | `0x00`（保留，必须 0） |
| 5 | 1 | ST | `0x01`=动作/吸合；`0x00`=复位/断开 |

示例：

```
55 01 02 05 00 01   ; 工位2 气缸下压
55 01 02 05 00 00   ; 工位2 气缸复位
55 01 01 01 00 01   ; 工位1 继电器1 吸合
55 01 00 05 00 01   ; 广播：全部工位气缸下压
```

### 4.2 通道 CH

| CH | 名称 | ST=`0x01` | ST=`0x00` | 到位时限（须在此时限内回 `0x81`） |
|----|------|-----------|-----------|----------------------------------|
| `0x01` | 继电器 1 | 吸合 | 断开 | ≤ 200ms |
| `0x02` | 继电器 2 | 吸合 | 断开 | ≤ 200ms |
| `0x03` | 继电器 3 | 吸合 | 断开 | ≤ 200ms |
| `0x04` | 继电器 4 | 吸合 | 断开 | ≤ 200ms |
| `0x05` | 气缸 | 下压 | 复位（抬起） | ≤ 2s |

`0x06~0x0F` 保留。

### 4.3 标准命令（按工位替换 SLOT）

下列以 `SLOT=ss` 表示，`ss` 取 `01`~`0F` 或广播 `00`：

| 功能 | Hex |
|------|-----|
| 气缸下压 | `55 01 ss 05 00 01` |
| 气缸复位 | `55 01 ss 05 00 00` |
| 继电器1 开/关 | `55 01 ss 01 00 01` / `… 00` |
| 继电器2 开/关 | `55 01 ss 02 00 01` / `… 00` |
| 继电器3 开/关 | `55 01 ss 03 00 01` / `… 00` |
| 继电器4 开/关 | `55 01 ss 04 00 01` / `… 00` |

### 4.4 控制到位应答（强制）TYPE=`0x81`

每条 TYPE=`0x01` 控制请求，治具**必须**回一帧（广播时按工位各一帧）TYPE=`0x81`。

**回包时机（强制）**：

| 通道 | `STATUS=0x00` 的含义 | 判定要求 |
|------|----------------------|----------|
| 气缸 `CH=0x05` | 机械**已到位** | 须依据到位传感器 / 限位开关等确认下压到位或抬起到位；**禁止**收包后立刻回成功，也禁止仅靠固定延时当成功 |
| 继电器 `CH=0x01~0x04` | 开关**已完成** | 驱动完成且稳定；可在线圈驱动确认后回包，时限见 §4.2 |

超时未到位：仍须回 `0x81`，`STATUS` 填失败码（见 §4.4.2），不得静默。

| 偏移 | 长度 | 字段 | 说明 |
|------|------|------|------|
| 0 | 1 | SOF | `0x55` |
| 1 | 1 | TYPE | `0x81` |
| 2 | 1 | SLOT | 点名请求：与请求相同；广播：填**实际动作工位号**（不是 `0x00`） |
| 3 | 1 | CH | 与请求相同 |
| 4 | 1 | ST | 与请求相同（回显目标状态） |
| 5 | 1 | STATUS | 见 §4.4.2 |
| 6 | 1 | EOF | `0xAA` |

成功示例：

```
→ 55 01 02 05 00 01        ; 工位2 气缸下压
… 气缸运动 …
← 55 81 02 05 01 00 AA     ; 工位2 下压到位

→ 55 01 01 01 00 01        ; 工位1 继电器1 吸合
← 55 81 01 01 01 00 AA     ; 继电器动作完成
```

失败示例（气缸超时未到位）：

```
← 55 81 02 05 01 05 AA     ; STATUS=0x05 到位超时
```

#### 4.4.1 语义边界

| 禁止 | 说明 |
|------|------|
| 受理即成功 | 收到 `0x01` 后立刻回 `STATUS=0x00`，而气缸尚未到位 |
| 无应答控制 | 控制成功或失败都不回 `0x81` |
| 用延时代替传感器 | 气缸无限位/传感器却一律延时后回成功（验收不合格） |

上位机侧：发出控制后等待对应 SLOT+CH+ST 的 `0x81`；仅当 `STATUS=0x00` 才继续下一步（如读电流）。

#### 4.4.2 控制 STATUS

| STATUS | 含义 |
|--------|------|
| `0x00` | **到位 / 动作完成**（成功） |
| `0x01` | SLOT/CH 无效（未动作） |
| `0x03` | 硬件故障（驱动/传感器异常） |
| `0x04` | 工位忙（一拖多资源占用，可重试） |
| `0x05` | **到位超时**（已驱动但未在时限内确认到位） |
| `0x06` | 气源 / 互锁不允许动作 |
| `0xFF` | 未知错误 |

### 4.5 广播 SLOT=`0x00`

| 规则 | 说明 |
|------|------|
| 允许 | 仅 TYPE=`0x01` 控制帧 |
| 禁止 | TYPE=`0x02` 测量请求（电流必须点名工位） |
| 行为 | 所有已使能工位执行同一 CH/ST |
| 到位应答 | **强制**：每个实际动作工位各回一帧 `0x81`，SLOT 填实际工位号；某工位失败则该工位 `STATUS≠0`，其它工位仍须各自回包 |
| 完成判定 | 上位机收齐预期工位的成功 `0x81` 后，才视为广播动作完成 |

### 4.6 行为要求

1. 只动作 **SLOT 命中** 的工位资源；其它工位状态不变。
2. 非法 SLOT / CH：不动作，须回 `0x81` 且 `STATUS=0x01`。
3. 上电默认：各工位继电器全断、气缸抬起（无需因上电主动狂发 `0x81`）。
4. 同一 SLOT+CH 重复相同 ST：若已处于目标到位态，可立即回 `STATUS=0x00`（保持，不抖动）。
5. 运动过程中收到对同一 SLOT+CH 的相反 ST：按新目标执行，最终只对**最后一次请求**回对应 `0x81`（说明书须声明是否支持中途改向）。

## 5. 电流读取

### 5.1 请求（6 字节）

| 偏移 | 长度 | 字段 | 说明 |
|------|------|------|------|
| 0 | 1 | SOF | `0x55` |
| 1 | 1 | TYPE | `0x02` |
| 2 | 1 | SLOT | **必须为 `0x01~0x0F`**，禁止 `0x00` |
| 3 | 1 | CH | `0x01`=CH1；`0x02`=CH2；`0x00`=该工位全部电流通道 |
| 4 | 1 | RES | `0x00` |
| 5 | 1 | OP | `0x01`=读一次 |

```
55 02 03 01 00 01   ; 读工位3 的 CH1 电流
55 02 03 00 00 01   ; 读工位3 全部电流通道
```

收到 `SLOT=0x00` 的测量请求：不测量；若可应答则一帧 `STATUS=0x01`（通道/槽位无效）。

### 5.2 应答（11 字节，`LEN=0x0B`）

| 偏移 | 长度 | 字段 | 说明 |
|------|------|------|------|
| 0 | 1 | SOF | `0x55` |
| 1 | 1 | TYPE | `0x82` |
| 2 | 1 | LEN | 固定 `0x0B` |
| 3 | 1 | SLOT | 与请求相同 |
| 4 | 1 | CH | 本帧通道 |
| 5 | 2 | I | 有符号大端，单位 **0.01 mA** |
| 7 | 1 | STATUS | 见 §5.4 |
| 8 | 1 | RES | `0x00` |
| 9 | 1 | EOF | `0xAA` |

```
实际电流(mA) = (int16_t)I / 100.0
```

成功示例（工位3，CH1=12.34mA）：

```
55 82 0B 03 01 04 D2 00 00 AA
```

### 5.3 一工位多电流通道

请求 `CH=0x00` 时：对该 SLOT 下每个电流通道各回 **一帧** §5.2，按 CH 升序；禁止合成变长单帧。

### 5.4 测量 STATUS

| STATUS | 含义 |
|--------|------|
| `0x00` | 成功 |
| `0x01` | SLOT/CH 无效 |
| `0x02` | 测量未就绪（可重试） |
| `0x03` | 硬件故障 |
| `0x04` | 工位忙（一拖多资源占用，可重试） |
| `0xFF` | 未知错误 |

### 5.5 时限

| 项 | 要求 |
|----|------|
| 单通道应答 | ≤ 500ms |
| 一工位全部通道 | 末帧 ≤ 1s |
| 一拖多连读 | 上位机按工位串行请求；治具按请求顺序应答，不得错 SLOT |

## 6. 一拖多联调时序示例

四工位共用串口，逐个上电压合读电流：

```
; 工位1
55 01 01 01 00 01          ; 继电器1 吸合
← 55 81 01 01 01 00 AA     ; 继电器到位/完成
55 01 01 05 00 01          ; 气缸下压
← 55 81 01 05 01 00 AA     ; 气缸下压到位（传感器确认后）
55 02 01 01 00 01          ; 读电流
← 55 82 0B 01 01 .. AA

; 工位2
55 01 02 01 00 01
← 55 81 02 01 01 00 AA
55 01 02 05 00 01
← 55 81 02 05 01 00 AA
55 02 02 01 00 01
← 55 82 0B 02 01 .. AA

; 广播抬起
55 01 00 05 00 00          ; 全部气缸复位
← 55 81 01 05 00 00 AA     ; 工位1 抬起到位
← 55 81 02 05 00 00 AA     ; 工位2 抬起到位
; … 其余工位同样各回一帧
```

**资源互斥**：若多工位共用一套气源阀岛且不能同时下压，供应商必须在说明书标注「互斥组」；上位机将按互斥组串行调度。

## 7. 推荐单工位时序

```
55 01 01 01 00 01     ; 继电器上电
← 55 81 01 01 01 00 AA
55 01 01 05 00 01     ; 气缸下压
← 55 81 01 05 01 00 AA   ; 须到位后再发读电流
55 02 01 01 00 01     ; 读电流
← 55 82 0B 01 01 .. AA
55 01 01 05 00 00     ; 气缸复位
← 55 81 01 05 00 00 AA
55 01 01 01 00 00     ; 继电器断开
← 55 81 01 01 00 00 AA
```
