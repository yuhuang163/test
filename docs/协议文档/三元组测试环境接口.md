# 三元组测试环境接口

测试用例通过 `Channel=Cloud` + `DeviceCmd` 下发；实现见 `business/tuple/qtupleservice.cpp`。

## 云端地址

| 环境 | Param_baseUrl |
|------|---------------|
| 测试（dev） | `http://192.168.204.166:9185` |
| 正式（prod） | `https://lute-aiot-mac.luteos.com` |

默认取自 `SETTINGS` 键 `Tuple/BaseUrl`，缺省 `http://192.168.204.166:9185`。

## 接口与参数

| 接口命令 | Action | 需填参数 | 底层接口 |
|---------|--------|---------|---------|
| `Login` 三元组云端登录 | Set | `Param_baseUrl` 环境地址；`Param_userName` 账号（测试 `M8_rc`/`M10_rcd`，正式 `M8_QC`/`M10_QC`/`BYD_M5U_QC`）；`Param_password`（`Aa123456`） | `GET /api/mac-addresses/auth` |
| `ApplyTupleByMac` 获取云端三元组 | Get | `Param_mac`（`$MAC` 或留空）；`Param_sku`（如 `PH9`）；`Param_position`（`1`左 / `2`右 / `3`单只 / `F`未指定） | `GET /api/mac-addresses/applyTupleByMac` |
| `DebugUpdateMacStatus` 上报烧录状态 | Set | `Param_mac`（`$MAC`）；`Param_status`（`1`烧录 / `2`蓝牙）；可选 `Param_sn`（`$SN`） | `POST /api/mac-addresses` |
| `ResetStatus` 复位状态 | Set | `Param_mac`（`$MAC`）；`Param_status`（`1`复位） | `POST /api/mac-addresses/reset-status` |
| `ReportWriteRecord` 检验数据上报 | Set | 无参数 | `POST /api/inspection/report` |

> `Login` 须在 `ApplyTupleByMac` 之前执行；`ApplyTupleByMac` 返回 `productKey` / `deviceName` / `deviceSecret` / `sn` / `availableCount`。
